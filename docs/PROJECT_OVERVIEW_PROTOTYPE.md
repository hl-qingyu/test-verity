## 演示数据与口径

概览从当前浏览器项目的已有资料、用例及五类分析记录读取；示例项目复用原模块已有虚构数据初始化，不另造概览业务记录、重复报告或完成状态。空项目不种样例。界面明确「浏览器交互原型」，不是后台项目统计或实际质量结论。

- 需求/原型资料按未删除、未归档的来源身份计数，同一来源的多个版本不重复计数；GitHub/链接按来源计，不按页面或路径数量计。
- 活动用例排除停用与删除身份，候选、设计版本及测试记录不计入数量。
- 执行中仅主分析记录的排队/分析中状态；不累计生成批次、对话或应用条目。
- 需求风险包含人工风险；用例分析草案应用后，问题未关闭仍需关注；代码和变更沿用各自人工处理状态。
- 用例生成按有待审建议/未形成业务结论的记录分别计数，两分项可重叠、不相加；已应用、已复用、已忽略的候选排除。
- 变化说明不当成发现，回归建议的待审阅/暂缓单列；各模块不加成一个项目缺陷总数。
- 需求任务和明确绑定的报告只占一条近期记录，任务/报告原件保留；未声明结果完整性时显示待查看，不从完成状态猜测全量完成。
- 已成功应用或复用的条目不再显示待处理入库失败，旧失败审计不修改。历史失败分析仍保留，不据此自动重试。

原型兼容当前浏览器演示结构与已保存历史；不提供把真实后端JSON直接上传为概览数据的入口，不替代正式配对导入校验。

## 交互

1. 四卡可进入资料/活动用例；执行中卡切换并定位近期筛选。五类分析入口进入原模块，在原模块新建，不自动分析。
2. 近期提供全部、执行中、已完成、失败，先过滤再取8条；按创建时间排序，处理记录不使其重新置顶。页签支持方向键、Home/End、Tab和Enter；无全历史列表或独立任务中心。
3. 单条查看定位原模块的指定记录。关注分项涉及多条记录时，仅提供只读记录选择弹窗，选择后带入原模块对应页签及状态；不在概览进行审核或写入。
4. 原模块显示「来自项目概览」提示，提供清除筛选/返回概览。代码与生成的概览条件只作用于选定项目、记录和明确分项；不改变报告和人工处理状态。
5. 概览目标保存在当前原型URL的固定 `ov` 参数中，仅含项目/模块/记录身份和筛选。刷新/前进后退重新核对当前项目及已有记录；记录不存在、项目不匹配或事项变化时明确拦截，不悄悄显示另一条记录。此为HTML本地交互，不是正式应用已接通深链接。
6. 刷新以400ms本地合成等待演示加载，回到页面时展示最新本地数据；切项目、离开页面或新的刷新会使旧回调失效。不采集网络状态、不轮询服务端或自动重跑分析。
7. 页面下方「原型状态演示」提供正常、加载中、部分不可用和读取失败；失败不展示假零，部分不可用保留其他区块。该切换只改变页面演示状态，不改业务数据。

浏览器原型没有正式登录/项目权限验证，不能把当前角色演示或URL校验称为后端鉴权。正式权限、数据性能及10秒可见页面轮询仍按设计方案后续实施。
