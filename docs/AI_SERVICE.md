## 使用流程与原型

入口：平台设置 → AI 服务。按用户确认展示 Codex / Claude / DeepSeek 三卡片，首期仅 Codex 可用（仍使用现有Responses API接入）；保留配置名称、API Base URL、模型名称、API Key 的顺序与两列布局，保留测试连接、保存配置。

- 默认使用平台统一服务。每位用户仅一份个人配置，平台仅一份统一配置。
- 个人配置需先完整保存，再切换使用来源。切换即时保存，失败保持原选择；版本冲突需重新加载。
- 编辑个人/平台配置不会自动改变当前用户的使用来源；个人服务失败不会自动使用平台密钥。
- 配置名称必填，最长80字符；模型 ID 必填，最长160字符，手工填写供应商已开通模型。
- API Key 首次必填；已有密钥时留空保留、输入替换。改变 Base URL 必须重新输入密钥。无查看原密钥、清空密钥或删除配置入口。
- 保存只做字段校验和加密入库，不发送模型请求。允许未测试就保存，保存成功不等于测试通过。
- 测试针对当前表单；没有输入 Key 时仅取该范围已保存的 Key，测试不修改配置。修改表单后移除旧测试提示。

去掉结尾斜杠后直接拼接 `/responses`，模型目录拼接 `/models`，不自动添加 `/v1`。保留 HTTPS（默认443端口）、禁止用户名密码／查询参数／片段、显式非公网IP及localhost、点路径校验；不跟随重定向、不使用环境代理。第三方协议兼容需实际连接验证；仅支持 Chat Completions 或 Claude 原生协议的中转不适用现有通道。

测试发送 `input="请只回复 OK"`、`store=false`、`max_output_tokens=256`、`stream=false`，不附加业务资料、工具或文件。输出必须是完成状态且有非空文本才显示成功；超限/未完成不会报成功。

异常区分：401鉴权失败、403拒绝访问、404模型/接口不可用、429额度或限流、网络异常、超时、响应格式错误、未完成输出、版本冲突、密钥存储异常。只返回固定错误码，不转发上游正文、密钥、堆栈。测试沿用每进程限流，每个用户/IP每分钟最多20次。
