## 使用

原型资料顶部点击“上传目录”，通过系统文件夹选择窗口选取目录，填写资料名称、分组和页面 / 交互说明，在文件树中确认上传范围后保存。默认勾选支持的文件，可按目录 / 单文件取消，可搜索、选择当前可见文件或清空。取消选择窗口保留当前草稿。

一份目录是一条原型资料，目录内文件保持相对路径。平台保存上传副本供项目成员共享，不持续访问用户电脑。上传和预览不会启动 AI；项目设置中的“本地代码”仍按原浏览器目录授权规则工作。

支持 HTML/HTM、CSS、JS/TS/JSX/TSX、Vue、JSON、MD、TXT、SVG、PNG/JPG/JPEG/WEBP。版本控制、依赖、构建目录、凭据 / 私钥路径及不支持格式会在页面明确列为排除项，其正文不上传。相对路径最多 512 字符，不接受绝对路径、双点路径或重复路径。不截取文件清单或正文；实际资源不足会失败，不能以部分上传冒充完整目录。

右侧可展开目录、搜索并点击文件名查看。文本预览前 100,000 字符并提示截断，下载与分析使用完整文件；图片按原比例展示。HTML 通过“在浏览器打开”使用隔离预览。2026-10-20 修复仅返回 HTML 导致样式丢失的问题：按 HTML / CSS 所在路径，解析同一固定目录版本中的相对 CSS、JS、图片和 CSS 引入，校验原件哈希后嵌入预览响应；查询参数不影响固定文件匹配，CSS 循环引用终止。内嵌样式中的图片引用同样处理。

预览继续禁止平台同源权限、外部网络 / 平台接口、表单和顶层导航；不在后端执行脚本。只处理已经上传到该版本的静态相对资源，不读取用户电脑、其他版本、缺失或外部资源，不提供完整站点服务；动态请求、模块导入及依赖浏览器同源存储的功能仍可能不可用。下载原件与分析输入不做此转换，分析继续只读取明确勾选的文件，不随预览自动扩大 AI 范围。

“下载目录包”导出标准 TAR，包内保留中文及多层相对路径。“上传目录新版本”重新上传本次勾选的完整快照，旧版本、已删除路径的旧原件及历史分析依据保留。资料分组与逻辑删除沿用原权限和记录规则。

## 分析范围

- 需求分析、代码分析的资料依据、用例分析及用例生成均可选择“目录资料 → 固定版本 → 文件树”。选择目录资料不会自动向 AI 发送整个目录，必须明确勾选文件。
- 原型变更新增“本地目录”来源，选择两个固定版本和相对路径范围；读取两个完整目录索引，只有索引证明某路径不存在才作为新增 / 删除。图片变化按原件哈希提示，文本提供双侧正文差异。
- 变更分析的补充资料同样支持固定目录版本和文件范围。切换版本清除旧范围及对应确认，避免沿用其他版本的路径。
- 用例生成维护时可分别选择旧目录版本的文件和当前版本的文件，不把当前文件冒充历史输入。
- 页面批注 / 说明文件可随目录上传，并在文件树中与页面一起选择。目录按选中文件原文提供，不执行 JS 或自动读取未勾选依赖；原型链接的受限静态批注采集规则保持。

后端逐份核对项目、来源类型、版本归属、路径成员及内容哈希；文件正文和图片附件进入现有各分析固定输入。固定输入重试使用原版本 / 原范围，目录更新不会替换历史正文。AI 配置、Worker、计费确认、结果校验和人工处理规则沿用原模块，不自动发起真实分析。

双 JSON 导入可以绑定目录资料的固定版本；根据输入中的明确文件位置核对完整原文 / 图片引用，拒绝篡改或不存在的路径。不会仅凭目录名称或当前版本接受历史来源声明。

## 接口与调用链

前缀 `/api/projects/{project_id}/prototypes`：

| 方法与路径 | 行为 |
| --- | --- |
| POST `/directories` | 创建首个完整目录版本 |
| POST `/directories/{source_id}/versions` | 上传同一资料的完整新版本 |
| GET `/directories/{source_id}/versions/{version_id}/files` | 固定版本目录清单、文件字节数与 SHA-256，不返回私有存储键 |
| GET `/directories/{source_id}/versions/{version_id}/file?path=…` | 鉴权下载单文件；只有受支持图片可 inline |
| GET `/directories/{source_id}/versions/{version_id}/preview?path=…` | 文本 / 图片预览类型 |
| GET `/directories/{source_id}/versions/{version_id}/browser?path=…` | HTML/HTM 隔离预览 |
| GET `/directories/{source_id}/versions/{version_id}/archive` | 按固定索引导出保留原相对路径的目录包 |

上传复用公共 `api/http`、Origin、资料库 revision、上传 UUID 和私有存储；原始流为浏览器构建的未压缩 TAR 封装，首项 `manifest.json` 包含元数据及路径 / 大小清单，后续文件使用固定数字成员名。浏览器将原 File 作为 Blob 分片，不先把所有正文加载到 JS 内存。未引入依赖，也不接受服务器磁盘路径。

后端只接受所声明的完整文件顺序 / 数量 / 大小，不按用户路径解压，不接受链接成员或多余数据；逐份校验格式 / 编码 / 私钥内容和哈希后，才在项目锁、资料库 revision 下创建可见版本。传输等待不保留数据库事务，发布前复核账号和项目访问。相同 UUID、相同输入幂等；不同正文或元数据冲突。失败 / 中断不发布半份目录，提交响应不确定时保留已改名文件供恢复核对，不自动重发。

调用链：`Prototypes → PrototypeEditor / PrototypeDirectoryFiles → prototypeDirectory / prototypeApi → api/http → prototypes/router → prototypes/directories → documents`。各分析单向调用同一固定目录读取器；文件树提取为共用 `CodeFileTree`，原代码来源继续复用。
