## 分类

- 项目级用例分类，名称可自定义，例如用户端、Web端、门店端。同项目不能重名，可创建和编辑名称。
- 管理分类中提供删除图标，所有删除均需弹窗确认。空分类确认后删除；有关联用例时必须选择另一个具名分类，将全部关联用例迁移后再删除。没有其他分类时提示先创建；目标不能是自身或已不存在的分类。不删除用例，不改变编号、内容或历史记录。取消不做修改。
- 每条用例属于一个分类，允许未分类。分类独立于功能模块，不增加默认14列；在列表筛选区、详情和导入批次中选择。
- 列表可逐条/本页勾选，跨分页批量调整分类；切换项目清空选择，分类过滤与字段搜索同时生效，切换分类回第一页。
- 分类使用稳定标识，编辑名称不改变用例编号和历史记录。有项目访问权限的用户均可查看和执行已开放操作，不按创建人、负责人或成员身份划分私有数据。

## 导入流程

上传 → 工作表/表头选择（Excel）→ 14字段映射 → 校验预览 → 选择整批分类/重复处理 → 确认入库。

| 校验项 | 最终规则 |
| --- | --- |
| 文件格式 | XLSX、XLS、CSV；空文件、损坏或加密文件拒绝解析，不恢复20MB上传限制 |
| 字段映射 | 同名表头自动匹配，可手动调整；同一源列不重复映射，额外列忽略并提示 |
| 必填校验 | 不校验必填；缺列、空单元格保留为空，不自动补“无”或“未测” |
| 序号/编号 | 不采用导入值；平台项目内自增分配，导入编号重复不阻断；原值仅保留作来源 |
| 用例类型 | 允许空；有值沿用功能需求、逻辑校验、异常用例、边界用例、兼容性用例，未知值在预览中映射/修正 |
| 优先级 | 允许空；有值为P0、P1、P2、P3、P4，小写/首尾空格可规范化 |
| 测试结果 | 允许空；有值为未测、通过、失败、阻塞、跳过、废弃，其他值需映射/修正 |
| 测试人员/备注 | 允许空；有执行结果但测试人员缺失仅警告，不阻断 |
| 空行 | 全空行跳过，有业务内容则保留，不因缺少其他字段而丢弃 |
| 多行内容 | 保留单元格内换行和时序，不校验步骤与预期行数相同 |
| 合并单元格 | 映射字段的数据区合并单元格报错，要求拆开填写，不自动向下猜测填充 |
| 公式 | 映射字段中的公式要求先转为值；不执行公式、不依赖过期缓存 |
| 重复内容 | 批内或项目既有相同内容标为疑似重复，可选跳过/仍然新增，不自动覆盖 |
| CSV | 识别编码并预览，正确处理引号内逗号、换行和中文；没有工作表选择步骤 |

错误需显示工作表/行号/字段/原因，修正后才允许整批确认；警告可确认继续。确认再校验权限与输入，整批成功或失败，重复确认不重复入库。默认待审核，导入测试结果单独保留为导入记录，审核不等于测试通过。保存原件、表/行、原编号及原结果等来源，不覆盖已有用例。
