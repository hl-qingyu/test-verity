## 当前实现

入口：项目设置 → 本地代码，位于GitHub仓库之后。复用项目权限、Form、Select、CaseDialog和FilePicker中的DirectoryPicker主题按钮。

1. 项目负责人/管理员点击添加，填写来源名称、代码类型，选择自己的目录。类型包含后端、前端、移动端、原型、其他。
2. 系统目录授权由浏览器执行，只申请read权限。平台不填写或读取后端电脑路径，不申请写权限。浏览器只提供末级目录名，UI不伪造绝对路径。
3. 读取文件树，勾选整个目录、子目录或单文件。目录范围包含后续新增文件；单文件范围不会自动扩展。取消已选目录中的某项，会将其他选中项收窄为当前单文件范围，页面明确说明。
4. 保存时重新读取所选最新内容，在本浏览器保存首次基准。再次点击“读取最新内容”时重新遍历和读取，与上次本地快照比较，不要求手动创建版本或上传。
5. 读取变化记录按发现时间倒序，每页20条；支持前后内容对照、查看该次完整快照和无变化记录。首次读取以新增文件建立基准；加入/移出范围单独标记，不冒充磁盘新增/删除。
6. 名称和类型可编辑；已绑定目录不能替换成其他目录覆盖历史，另一个目录需新建来源。同一浏览器可识别的相同目录阻止重复关联。
7. 读取失败、取消、目录权限失效不保存新快照。二进制及非UTF-8内容标记未能比较，不误判成删除。

本期不做目录删除入口（已确认原型没有此操作）、Git提交历史、后台自动监控、AI/Skill、分析任务或自动执行代码。

## 数据位置与权限

后端只保存项目目录关联的元数据：名称、类型、授权人、目录末级名称、关联UUID和编辑版本。**源码、相对文件路径、文件内容和读取历史不发送后端**；没有上传新版动作或源文件写入操作。

浏览器IndexedDB数据库 `verity-local-code`：

- bindings：以用户ID、项目ID、关联UUID组成的键保存DirectoryHandle、读取范围和最后读取序号。
- snapshots：以绑定键和序号为复合键，保存每次读取的文件内容/哈希/大小/修改时间、跳过原因、范围、开始/发现时间和变化列表。通过add追加，不覆盖历史；与bindings序号在同一事务提交。
- 并发读取以旧序号校验，落后请求返回冲突；存储额度不足/事务中止时不删除旧记录、不报保存成功。没有静默淘汰历史。

关联元数据属于项目，项目成员可查看。授权与本地代码属于授权账号；只有该账号且仍为项目管理者才能从页面编辑或发起新读取，其他成员/管理员不会因此得到磁盘授权或代码内容。前端读取前后重新检查项目访问；后端写入再次检查项目管理权限。

同一浏览器中的账号隔离是应用作用域，不是操作系统隔离；控制该浏览器开发工具的人仍可能访问其本地存储。更换浏览器、访问域名/端口或电脑、清除网站数据、浏览器存储回收后不会从后端恢复代码历史。重新授权后在新浏览器建立新基准，不能把另一个设备当作上次读取比较。

目录授权失效时点击重新授权；浏览器未保存句柄时重新选择目录。已有句柄用isSameEntry确认同一目录；句柄已丢失时只能核对名称，此浏览器从空基准开始，不继承其他电脑的读取历史。

新建代码分析弹窗选择本地代码来源后，点击“读取本地代码树”会同时处理授权：已有句柄但权限失效时直接触发浏览器重新授权；当前浏览器没有句柄时直接选择目录。所选目录必须与来源登记的末级目录名称一致，成功后句柄仍保存到当前浏览器。该入口只读取文件树和选择范围，不因此调用AI或提交分析任务。

后续AI分析若需后端处理，仍须发送经选择的代码并固定当次证据。本期没有连接AI或自动同步代码，不能把当前本地浏览器历史当成已持久化的服务器报告依据。

## 浏览器与读取边界

依赖支持File System Access目录选择的浏览器及安全上下文，通常使用Chrome/Edge的HTTPS或本机localhost/127.0.0.1。能力不存在时显示明确提示，禁用目录授权，不偷偷退回上传文件夹。目录系统选择/权限弹窗不能伪造。

引用：[目录授权](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker)、[重新申请读取权限](https://developer.mozilla.org/en-US/docs/Web/API/FileSystemHandle/requestPermission)。

2026-09-14用户要求取消读取文件数量与大小限制：不再限制目录条目数、选中文件数、单文件大小或总大小，不截取前N条，不因文件过大跳过。保留32层目录深度、512字符相对路径检查及敏感文件排除。非UTF-8/二进制仍明确标记未能比较；实际浏览器内存/存储资源耗尽时不能保证读取成功，保存事务失败不覆盖旧历史。

默认排除.git/.svn/.hg、.env及其变体、常见凭据/私钥、依赖、构建产物和常见二进制；不执行代码或Git命令。只遍历浏览器授权句柄的子项，不接收服务器给出的本机路径；拒绝包含路径分隔符、控制字符、点/双点段的异常条目。文件名排除不代表能识别源码内所有密钥，用户仍需核对所选范围。

文件内容计算SHA-256判断变化，不单凭修改时间。读取后重新获取文件大小/mtime，检测到读取期间修改则整批失败；整个目录不是文件系统原子快照。发现时间来自用户设备时钟，不代表精确修改时间，不还原两次读取之间的多次编辑。

## 后端结构

调用链：项目设置 → LocalCode → localCodeApi → api/http → modules/local_code/router → service → projects.access_project → 数据库。

| 接口 | 权限/作用 |
| --- | --- |
| GET /api/projects/{project_id}/local-code | 项目可见性校验，只返回关联元数据 |
| POST /api/projects/{project_id}/local-code | Origin、项目管理权限、当前用户身份；创建或编辑自己的目录关联 |

POST仅允许client_id、name、directory_name、kind、version。禁止owner_id、任意磁盘路径或代码正文；owner_id从当前登录身份取得。新建version=0，重复UUID且相同数据幂等返回已有记录；修改要求当前版本，过期版本409。关联按project_id/owner_id/client_id唯一，不共用其他用户授权。

迁移 `20260914_19`（前序18由同工作区的原型路径说明改动占用）新增 `local_code_source`：

| 字段 | 含义 |
| --- | --- |
| id | 关联主键 |
| project_id / owner_id | 所属项目/授权账号，真实外键 |
| client_id | 浏览器生成稳定UUID，重复提交去重 |
| name / directory_name | 显示名称/末级目录名称 |
| kind | BACKEND / FLUTTER / WEB / PROTOTYPE / OTHER |
| version | 乐观锁版本，必须大于0 |
| created_at / updated_at | 带时区创建/更新时间 |

所有表/列均声明中文数据库COMMENT。降级发现关联数据时拒绝删除，不清空历史。没有改变GitHub仓库表、其他项目业务表或用户既有目录。
