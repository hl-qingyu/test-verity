# GitHub 连接与项目仓库

## 现行规则

项目唯一标识由平台生成，同名项目可并存。GitHub 使用当前操作者自己的只读授权，后端核对项目及仓库白名单。绑定来源保存固定提交和必要路径。

以往阶段和验证记录见 [历史记录](archive/GITHUB_PROJECTS_HISTORY.md)。

## 当前项目默认选择

当前项目在同一浏览器、同一站点下按登录用户分别记住最近一次选择（包括创建项目后和页面跳转时的选择），刷新或重新登录后优先恢复。浏览器仅保存账号分区的项目 ID 偏好，不保存项目正文或身份凭据，不跨浏览器、设备或站点同步；清除浏览器存储后重新使用默认选择。

恢复时以 `/api/projects` 返回的当前可见项目为准：原项目已删除或失去权限时回退到列表第一个可用项目，没有项目则保持空状态并清除失效偏好。请求失败或取消不覆盖原偏好，存储不可用时仍可正常切换项目。切换账号重新挂载工作区，避免沿用另一账号的项目选择与页面状态。

## 页面与操作

- 平台设置 → GitHub 连接：所有登录账号管理自己的多份连接。个人与组织分别配置，支持 Classic / Fine-grained PAT，GitHub App 显示待支持。只能使用 `https://api.github.com`。
- 字段按原型：连接名称、访问方式、API地址、连接类型、GitHub账号/组织名称、访问凭据。Token 支持 `github_pat_`、`ghp_` 和旧版40位十六进制格式；首次必填，留空保留，填写替换；更换所属个人/组织或类型需要重新填写可访问目标的Token，Classic可以复用同一枚。前端内存临时输入，不写浏览器存储。
- 测试当前输入，先验证GitHub身份，再分页读取本人及所属组织可访问仓库；按填写的所属方和类型过滤。个人连接还检查身份与所属个人一致。组织名称手工填写，不申请额外的组织成员读取权限，也不声称已独立核验完整组织成员名单。
- 身份验证和仓库列表发现成功，不等于已验证Contents权限。用户勾选后保存时，重新读取仓库元数据及默认分支，任何一项失败均不保存。空仓库没有分支时明确提示先初始化，未查到仓库不称连接成功。
- 每页100项，本次最多载入20页，每连接最多选20个仓库。可搜索已加载列表；测试重做或修改凭据/所属方后重新勾选。身份测试结果10分钟有效，过期要求重新测试。
- 项目选择旁“＋”：所有有效登录用户均可创建项目，填写名称、负责人、说明。唯一标识由平台自动生成，允许创建同名项目。创建请求中的 `identifier` 为旧客户端兼容字段，服务端忽略其值。普通用户创建时负责人固定为本人，管理员可指定其他有效账号；项目不自动加入全部账号。负责人可以修改项目基本信息，变更负责人仍需管理员。
- 项目设置：基本信息 / GitHub仓库 / 成员与权限 / 模块绑定，保持原型分组。成员与权限支持负责人/管理员添加或移除普通成员，不能移除负责人；模块绑定继续待接入。
- 项目设置 → GitHub仓库：负责人/管理员选择自己的连接和已勾选仓库，地址自动生成，选择类型及默认分支。保存前实时检查仓库和指定分支。每项目独立、可关联多个前后端仓库，同项目不重复关联同一GitHub仓库ID。
- 项目记录只保存仓库身份及配置，不保存/共享个人连接的Token。其他成员看到关联元数据不代表拥有GitHub访问权；未来读取代码仍须以请求人的连接及选中仓库授权重新验证。

## 后端权限与凭据

- GitHub账号连接严格 `owner_id = 当前登录用户`，管理员也无法读取、测试或修改其他人的连接。
- 项目读权限：平台管理员、项目负责人或项目成员。写权限：管理员/负责人。非项目成员请求返回404；项目成员写请求返回403。
- 凭据提交复用一次性RSA-OAEP/AES-GCM封装，绑定会话和路径；增加两个固定GitHub入口白名单。密文长度上限64KiB，容纳分页选择凭证；仍保持本地单Worker限制。
- 凭据使用已有后端主密钥做Fernet加密存储；未修改/输出 `.env`。接口仅返回 has_token 状态，不返回Token或密文。
- 仓库发现结果签发带用途、会话及连接参数指纹的短期加密凭证。保存的仓库ID必须来自这些凭证；不能伪造一个其他仓库ID绕过选择。
- 保存和项目关联都带版本检查。网络校验期间不持有数据库事务；返回后再次加锁检查当前权限、连接版本及仓库选择。失效Token、审批/访问限制、限流、超时、格式异常均返回脱敏错误，不自动重试。
- Fine-grained Token建议只选指定仓库，授予Contents Read和必要Metadata Read。平台不能凭Token前缀断言其没有额外写权限；即使用户提供超额授权Token，后端仍没有GitHub写入操作。

## 固定远端操作白名单

所有请求均为GET、固定 `api.github.com`，不跟随重定向、不读取环境代理、不接受任意URL/HTTP方法/命令。仅允许：

1. `/user`：验证当前GitHub身份。
2. `/user/repos?affiliation=owner,collaborator,organization_member&per_page=100&page=...&sort=full_name`：发现授权仓库。
3. `/repositories/{id}`：保存选中仓库前校验元数据。
4. `/repos/{owner}/{repo}/branches/{branch}`：验证选中仓库分支读取权限。仓库路径及分支均校验和编码。

上述元数据发现是连接/勾选过程；不能据此继续读取未选择仓库的文件。平台没有外部push、文件写入、分支/Tag修改、PR创建/合并或评论接口，也没有任意Git命令接口。

单次网络读写超时15秒，选中仓库最多4路并发校验，前端保存等待190秒；网络失败不声称已保存。GitHub API版本固定为官方文档本次核对的 `2026-03-10`。

## 平台接口

| 接口 | 用途 |
| --- | --- |
| GET /api/github/connections | 本人的连接与已选仓库列表 |
| POST /api/github/connections/probe | 加密提交当前表单，验证身份和读取一页候选仓库 |
| POST /api/github/connections | 加密提交、校验发现凭证及所选仓库，创建或更新本人连接 |
| GET /api/projects | 当前账号可见项目 |
| GET /api/projects/people | 管理员/已有项目负责人搜索可选有效账号，最多50项 |
| POST /api/projects | 有效登录用户创建项目；普通用户只能指定本人，管理员可指定有效账号 |
| PATCH /api/projects/{id} | 项目基本信息及版本更新 |
| GET、POST /api/projects/{id}/members | 查看/添加项目成员 |
| DELETE /api/projects/{id}/members/{user_id}?version=... | 移除成员关系，不删除账号 |
| GET、POST /api/projects/{id}/repositories | 查看及创建/修改当前项目仓库关联 |

平台POST/DELETE用于本地配置和关系，不会转换为GitHub写入。所有接口登录鉴权，写入校验Origin，响应禁止缓存。

## 数据与验证

迁移 `20260912_04`：新增github_connection、github_repository、project、project_member、project_repository五张表；已有账号、会话、AI配置不修改。新表采用外键、项目标识唯一及项目仓库唯一约束，迁移已审查并执行。

真实PostgreSQL测试使用外层事务回滚，GitHub上游为明确模拟，验证身份/凭据隔离、选中仓库限制、失效发现凭证、版本冲突、读取失败不保存、项目隔离、成员只读、他人Token不可借用，以及固定GET/域名/禁止重定向。模拟通过不是实际GitHub连接验收。

浏览器工具仍报 `unsupported Codex auth method: apikey`，未完成浏览器实点及窄屏视觉验收。用户需在正式页面填写自己的只读Token进行真实GitHub验证；不从本机应用或CLI取Token。无上传、推送或远端发布。


项目标识由后端自动生成（proj- 加 UUID），无需填写；已有标识只读且更新不修改。名称和负责人标注必填，负责人搜索合并到选择弹层，项目校验不使用 Token 文案。
