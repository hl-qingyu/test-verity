# 需求分析对话（首期真实API接通）

## 现行规则

对话按项目、报告及功能隔离，使用提问人自己的 AI 配置。引用和人工新增风险使用原报告资料与会话来源核对，新增事项独立保存。

2026-09-17已在首期需求分析对话基础上接入功能独立对话、风险引用和人工新增风险。首次AI分析也由同一`app.chat_worker`运行Skill v3任务；会话附件和补充系统资料仍未实现。

## 使用

右侧资料展示仅保留名称链接，不展开正文或片段预览。按已保存的资料绑定跳到需求/原型资料页并定位条目；已删除或缺失资料不展示可点击入口。资料管理页查看当前内容，对话依据仍保持提交时固定版本。

进入需求分析，打开已有分析结果，点击“需求分析对话”。独立页面左侧可切换需求分析对话、各功能对话和历史分析记录，中间聊天，右侧展示本次文字上下文范围。需求对话和功能对话按报告内function_key隔离历史及上下文；风险追问进入所属功能并保存risk_key引用，不创建风险专属会话。每轮调用只能使用该轮发起人自己的AI配置。

历史记录名称加粗，当前记录使用整项高亮、左侧强调线和“当前记录”文字；整张记录卡片是唯一导航链接，点击名称、时间或留白均可切换，Tab 聚焦后 Enter 也可切换。不改变原有路由或会话隔离。

发送前在后端固定当次 input（文字片段）、report（功能风险）、handling（最新人工结论）、revision及全部已完成问答。未读取图片/PDF原件、未重新抓取原型链接、不访问代码，不将既有图片观察说成实时识图。失败或取消轮次仍显示在历史，但不作为已完成问答重新送入模型。

当前需求分析对话只属于需求风险报告，不自动混入代码分析、用例分析或其他模块历史。联合复核暂缓，不进入当前需求分析或首期代码分析范围；后续如重新设计，应显式保存每轮 `context_refs`，不能把跨模块历史作为隐式公共上下文。

AI报告若带`review_warnings`，本轮对话固定上下文一并包含，提示模型相关摘录/覆盖尚待人工核对，不能复述成已证明的原文或测试通过；原报告和人工处理仍各自独立。

普通聊天不修改任何原始分析结果、风险或处理。已完成AI回复旁可打开“添加为风险点”，用户必须人工确认功能、等级、问题、固定原文依据、影响和建议后单独入库；取消无写入，UUID幂等，新增项参与累计清单、处理和导出。使用Responses流式协议接收上游，验证完整completed后保存并展示答案；界面状态轮询，不逐字显示不完整文本。每个对话历史分页40轮。草稿仅组件内保留，离页前请先发送。

每条提问最多8000字，资料及历史完整传递，不设置平台固定上下文字节上限，不静默裁剪；未实现长上下文摘要。实际可接受的上下文由当前模型及中转服务决定，平台完整传递不保证任意模型都接受。输出上限8192 token、网络读取等待600秒，失败由用户填回问题后主动发送，不自动付费重试。

## 实现与运行

前端`RequirementChat/chatApi`→公共`api/http`→`requirements/router`→`chat_service`；独立`app.chat_worker`→`chat_execution`→个人`analysis_configuration`→`responses.converse`。无新依赖。

接口前缀 `/api/projects/{project_id}/requirements/risk-reports/{report_id}/chat`：

- GET：最近40轮，`before`向前加载历史。
- POST：`request_id` UUID、`question`、`last_turn_id`；持久化排队，返回202。
- POST `/{turn_id}/cancel`：仅本轮发起人可停止。

同一功能对话的轮次串行，UUID幂等，旧历史版本409，数据库部分唯一索引防同一范围两个活动请求；不同功能可各自排队，由单Worker顺序执行。不同成员轮流提问使用各自配置。Worker再次核对发起人账号、项目权限和个人配置版本，外部等待前释放事务、返回后重查权限。取消仅阻止继续接收及保存结果，不能保证上游即时停止计费。

迁移`20260917_25`新增`requirement_chat_turn`，迁移`20260917_26`增加function_key/risk_key及需求分析任务、人工风险表，全部有真实中文COMMENT。后台使用数据库队列，不使用API进程内后台线程；单Worker依数据库会话咨询锁防重复启动，依次领取v3分析任务和聊天轮次，重启将RUNNING标记失败并保留QUEUED，不重发可能已计费请求。

启动API和前端之外，在backend运行：

```powershell

```
