# 需求原始资料

## 现行规则

需求资料按项目上传和分组，使用真实固定版本绑定附件和分析依据。更新会产生新版本，历史版本保留。删除预检显示引用，既有分析和旧验收点引用继续绑定原版本。

以往阶段和验证记录见 [历史记录](archive/DOCUMENTS_HISTORY.md)。

## 业务与权限

- 项目内保存原始文档和截图，不在资料页创建结构化需求、审批或确认状态。一个文档可描述多个需求，多份资料可共同说明一个需求。
- 管理员可访问项目；负责人及项目成员可创建分组、上传、移组、排序、查看和下载。非项目成员不可访问；每个读写接口均检查项目权限。成员身份按现有项目成员记录判断。
- 分组可独立创建，空组保留；同项目名称不能重复，1–80字，去除首尾空白，不允许保留名称“未分组”。上传下拉可选已有组或未分组。
- 具名分组旁可点击编辑图标（提示“编辑分组名称”），沿用创建时的权限、名称及revision校验；保存后上传下拉和列表同步更新。分组ID、文件关联及历史版本不变，“未分组”不能改名。
- 支持文件拖入分组、勾选后批量移组、组内上/下排序。拖动显示文件浮层、原位淡化和目标高亮；批量整理也可通过键盘使用。
- 文件有稳定ID；每次“上传新版本”新增一个整数版本，不修改旧文件。移组和排序修改文件归属，不重写版本记录。本轮不提供删除、重命名或归档操作。
- 原型的分析范围和来源多对多是后续设计。正式“分析所选资料”明确待接入，不保存假任务、不发送文件给AI、不产生分析结论。

## 上传与存储

- 格式：PNG、JPG/JPEG、WEBP、PDF、DOC/DOCX、XLS/XLSX、MD、TXT。校验扩展名、必要的文件签名/容器结构和文件名；拒绝空文件、路径字符和控制字符。
- 已移除前端、后端与数据库的20 MB上限。请求体分块写到私有暂存文件，计算SHA-256后登记版本；大小列为bigint。实际容量受磁盘/代理/网络约束，页面上传等待上限30分钟；不声称无限存储。
- 不新增multipart依赖：每个文件单独以application/octet-stream上传，元数据放在受校验的查询参数。多文件顺序提交；失败时保留已完成文件并提示剩余文件，避免把部分成功说成全部成功。
- 每个上传有UUID用于重复请求识别；同UUID及内容不重复生成版本，不自动重试。网络结果不明时仍需刷新核对，重新选择文件会建立新的上传请求。
- 上传弹窗支持单次多选和继续选择/拖入追加文件。取消系统文件选择器保持弹窗、分组及已有队列；待上传项右侧垃圾桶图标可移除该项，不删除已保存文件。上传中禁用移除。上传新版本仍仅接受一个文件。
- `Settings.document_storage_path` 默认 `backend/storage/documents`，可用 `DOCUMENT_STORAGE_PATH` 覆盖。文件使用服务器生成的随机键存储，不把用户文件名当路径，不通过静态目录公开；下载和预览均鉴权。
- 暂存文件正常结束或异常时清理。文件重命名与数据库提交不是分布式事务：提交结果不明确时保留文件，避免误删已提交原文；可能遗留的孤立文件需在核对数据库引用后人工处理。无自动删除历史文件任务。
- 原文不写日志，不发送AI/GitHub，不保存到浏览器localStorage。目录已被storage/忽略规则排除。

## 预览边界

2026-09-12更新：DOCX正文/表格与XLSX/XLS工作表预览已升级，覆盖下方早期“仅文字预览、XLS不支持”的记录。

- DOCX按正文顺序展示常见标题、段落、换行、列表标记和表格，支持gridSpan/vMerge常见合并；不保证Word页面排版，不展示嵌入图片、批注、修订痕迹或复杂控件。
- XLSX/XLS显示工作表实际名称、工作表切换、行列编号、单元格内容及合并区域。兼容日期、简单百分比及纯零格式的前导零；其他格式展示保存值，不声称完全还原Excel格式。XLSX公式展示表达式与缓存值（缓存缺失时为空），不重新计算；XLS仅展示保存的结果。图表、透视表和嵌入对象需下载原件查看。
- 复用office.py的安全XML/压缩包检查；新增固定版本openpyxl 3.1.5、xlrd 2.0.2。前者替代自行解析XLSX值类型，后者提供原有标准库不支持的BIFF/XLS读取；不引入Office自动化或远程文档预览服务。
- Excel最多20个工作表、每表200行50列、每格4000字符和合计100,000字符。Word最多500块、表格200行50列和100,000字符。解压后50MB及XLS解析50MB是预览保护，超出明确提示；不限制原件上传至20MB。
- 旧版DOC继续明确不支持在线预览，可下载或转换为DOCX。服务器没有Office/LibreOffice，没有擅自安装整套转换服务。
- 同一预览接口新增kind=word/workbook及blocks/sheets字段，前端使用parsePreview校验再渲染React元素，文档文字不能执行HTML/脚本。对外权限及文件版本行为不变。

- MD使用react-markdown和remark-gfm格式化显示标题、列表、表格、代码等，版本锁定在package.json/package-lock.json。链接仅通过附件关联打开平台固定版本，不跳转原地址；文内图片只显示说明，不请求本地或外部地址；原始HTML作为文本处理，不执行。TXT继续纯文本显示。原件及其URL编码不修改。

- 图片/PDF通过受权限保护的原件URL展示，不先把整个文件读入前端Blob。文件响应设置no-store、nosniff及限制内容执行的CSP；默认下载，只有图片/PDF允许inline。
- 图片可点击打开大图，支持10%–400%放大/缩小、原尺寸、适应窗口、Ctrl/⌘+滚轮和+/-键，超出区域可滚动查看；关闭按钮或Esc返回预览并恢复焦点。大图复用同一固定版本的鉴权URL，不改变原件或版本。
- MD/TXT展示转义后的原文，支持UTF-8、带BOM的UTF-16、GB18030，读取有界前缀并最多展示100,000字符，截断时明确提示；原件完整保存。
- DOCX本地提取段落和表格文字；XLSX展示工作表文件、单元格位置及内容，公式只显示保存的值和公式，不重新计算。不是完整Office排版，不还原嵌入图片。
- DOC/XLS提供原件下载并明确在线预览暂不支持。损坏内容/安全解析边界会返回明确提示，不伪造解析成功。
- Office预览保留独立的解压保护：最多3000个压缩条目、50 MB展开内容。超出时原件仍可保存，但不做在线解析；XML外部实体/DTD拒绝，不能执行宏、公式或上传内容中的指令。

## 调用链与数据

`Documents.tsx → documentApi.ts → api/http.ts → documents/router → documents/service → projects/service.access_project + db/models + documents/files`。

- `router`处理HTTP参数、身份、上传流和文件响应；服务负责权限、事务、版本及存储。`files.py`是本模块本地格式处理，不依赖HTTP或数据库。
- Alembic `20260912_06`只新增document_library、document_group、source_document、document_version四张表；组合外键限制跨项目分组/版本关联，保留原有数据。降级遇到已有分组或文件时拒绝，防止静默删除。
- 每个项目资料库有revision。创建分组、上传、移组、排序均在项目锁下检查revision；过期返回409。列表与revision在同一项目锁下读取，前端不乐观假装保存成功。

接口前缀：`/api/projects/{project_id}/documents`。

| 方法及路径 | 功能 |
| --- | --- |
| GET 空路径 | 分组、当前文件版本、资料库revision |
| POST /groups | name、revision创建分组 |
| PATCH /groups/{group_id} | name、revision修改分组名称 |
| POST /upload | 文件流；filename、upload_id、revision及可选group_id/document_id |
| POST /move | document_ids、group_id、revision批量移组 |
| POST /reorder | document_id、direction（-1/1）、revision调整顺序 |
| GET /{document_id}/versions | 版本列表及上传人/时间/校验值 |
| GET /versions/{version_id}/preview | 有界原文预览或明确不支持提示 |
| GET /versions/{version_id}/file | 鉴权下载；图片/PDF可inline=true |
