## 已确认且沿用

- 原型入口“项目资料 → 用例管理”，14列表格、点击编号查看编辑、搜索、结果筛选、导入、新建和导出Excel。菜单、列序不变。
- 14列顺序：序号、用例编号、功能模块、功能结构、用例类型、优先级、用例描述、验证用例子项、前置条件、操作步骤、预期结果、测试结果、测试人员、备注。
- 一行一条场景，多个操作步骤对应场景级预期；不要求步骤与预期行数相同。
- 用例编号由平台按项目自增生成，不使用导入编号；原值仅在来源记录保留。AI新用例默认未执行，导入通过只是导入测试记录，审核不等于测试通过。
- 需求关联、证据和审核状态不占默认14列；原件、历史版本不静默覆盖。

## 首期流程建议

1. 在当前项目查看列表，支持搜索编号/模块/功能结构/描述/验证子项，按测试结果筛选，分页及横向滚动。
2. 新建或编辑用例。新建自动分配序号及编号；设计内容变化追加版本，保留旧版。仅更新测试结果/测试人员时追加测试记录，不生成设计新版。
3. 导入XLSX/XLS/CSV：上传 → 选择工作表及表头行 → 14列映射（同名自动匹配，可调整）→ 逐行预览校验 → 用户确认入库。尾部空列和全空行忽略，多行文本保留；合并单元格不自动猜测业务含义，缺失必填内容报行级错误。
4. 导入只新增，统一分配平台编号；原表编号重复不阻碍导入。非空非法枚举等结构错误显示行号和原因；缺列/空值不算错误；有结构错误不允许整批确认。修正后重新预览。确认时再次检查权限及输入版本，平台分配编号防并发重复，成功后整批提交；重复确认同一导入不重复入库。
5. 导出当前搜索/筛选范围的全部用例（不是仅当前页），固定14列及单元格换行；按文本写入业务内容，防止以“=”开头的步骤变成Excel公式。
6. 本轮不提供物理删除。用例归档和恢复、批量维护、AI候选入库及分析另行确认。

## 字段与枚举建议

| 字段 | 规则 |
| --- | --- |
| 序号 | 当前查询结果的展示行次，跨页连续；导入序号不参与平台编号分配 |
| 用例编号 | 项目内自增整数，例如1、2、3；永久标识，不因分页/筛选改变；原导入编号仅保留作来源 |
| 设计字段 | 全部允许空白；导入缺列和空单元格保持为空 |
| 用例类型 | 沿用原型：功能需求、逻辑校验、异常用例、边界用例、兼容性用例。导入未知值在预览映射后确认，不静默丢弃 |
| 优先级 | 沿用原型：P0、P1、P2、P3、P4，允许空；导入非空未知值需处理 |
| 测试结果 | 未测、通过、失败、阻塞、跳过、废弃；空值保留为空。其他写法在导入预览映射，保存原值 |
| 测试人员 | 可留空，保存填写/导入时的名称；另行记录实际录入账号，不用录入人冒充执行人 |
| 审核状态 | 待审核、已审核，与测试结果分离；人工新建和导入默认待审核 |

## 版本与测试记录建议

- 当前列表展示最新用例设计版本及该版本最新测试记录，没有记录显示未执行。
- 修改任何设计字段形成新版，新版默认未执行、待审核。旧版的通过/不通过和测试人员不自动继承。
- 人工更正测试结果追加记录，保留被更正记录及录入人/时间；本期不以录入时间伪造真实测试执行时间。
- 导入原件保存在既有私有存储目录体系，来源记录保留原文件、工作表、原始行号、原编号/序号和原测试结果。
- 可从用例详情查看旧设计版本及各自测试记录。关联需求验收点、Skill/模板版本等未实现能力保留待接入，不编造可用规则。

## 权限建议

- 管理员、项目负责人、项目成员可查看、新建、编辑、导入、导出和录入测试结果；非项目成员不可访问。
- 有项目权限的用户均可审核、确认、编辑和执行已开放操作；不按负责人、创建人或普通成员限制需求/用例操作。项目成员管理和平台设置继续沿用原权限。
- 设计变更自动回到待审核，不把审核标记为运行测试成功。

## 接口与存储草案

前缀`/api/projects/{project_id}/cases`：GET列表、POST新建、GET/PATCH单条、GET设计版本、POST审核、GET/POST测试记录、GET导出；导入提供上传/预览、映射校验及确认端点，具体字段写入schemas，不做任意脚本或命令接口。

按cases/router、schemas、service分层，复用项目权限、公共请求、私有文件存储及已有openpyxl/xlrd。新增用例身份、设计版本、追加测试记录及导入批次必要表；不提前创建AI/需求规则表。迁移审查新增约束及中文表字段注释，不更改已有资料和账号数据。

## 验收

- 14列列序保持一致，用例编号按项目自增且忽略导入编号，多步骤/场景级预期不误判。
- 完整用例创建、编辑新版、审核权限、测试结果追加及旧版查询通过。
- XLSX/XLS真实导入预览、映射、换行、导入原编号不参与分配、非法字段、取消及重复确认检查通过。
- 多人并发创建和编辑不产生重复编号或静默覆盖；跨项目越权拒绝，项目成员审核/确认允许。
- 真实数据库事务回滚验证、架构/中文注释检查、Alembic一致性、前端请求/类型/格式/构建检查；浏览器核对14列表格与弹窗布局。外部AI不调用。

## 2026-09-12总原型交付

总HTML用例管理已补充：自增编号显示/新建/示例导入、10/20/50/100条分页、上下页/跳页、14列表头自选字段搜索（包含/等于/不包含，多个条件同时满足），搜索及每页条数改变回第一页。按当前搜索范围导出全部行。原型内部保留旧对象ID避免破坏现有引用，显示编号独立分配，导入原编号仅供追溯。
