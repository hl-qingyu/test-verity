1. 三栏：左分析记录、中结果、右固定范围。中间「分析问题 / 用例检查 / 对话」三页签；移除本模块旧覆盖率指标和验收点矩阵。

6. 完整新增/修改草案可编辑暂存并进入审核，无额外AI调用。宽审核弹窗左勾选、右完整正文/展开差异和依据、统一分类及单条覆盖；选项仅未分类/项目已有分类。复用目标保持旧分类，仍然新增须说明；已停用或过期复用目标拒绝。
7. 审核在浏览器内虚构库逐条应用，版本/设计/分类冲突失败继续、成功防重放；修改保留编号与旧设计/测试，新版已审核未测人员空，复用保留设计/测试并追加审核。入库不自动关闭问题。
